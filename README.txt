How to update your live GitHub website:
1. Unzip this folder.
2. Open your GitHub portfolio repository.
3. Delete the old website files or overwrite them.
4. Upload all files from this folder.
5. Commit changes.
6. Your GitHub Pages site will update automatically.

Important:
- Keep all HTML files in the repository root.
- Keep style.css in the same place as the HTML files.
- Replace the LinkedIn placeholder in contact.html with your real LinkedIn URL.
